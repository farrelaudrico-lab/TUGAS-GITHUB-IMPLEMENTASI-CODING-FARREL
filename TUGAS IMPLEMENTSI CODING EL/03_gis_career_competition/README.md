# 3. Career and Competition in Industrial Era with GIS

## Studi kasus
Mahasiswa ingin membandingkan peluang kerja teknologi pada beberapa kota contoh. Data memiliki koordinat buatan, jumlah lowongan simulasi, dan jumlah kandidat simulasi. Program menghitung rasio lowongan terhadap kandidat dan menampilkan posisi kota pada grafik koordinat.

## Tujuan
- Memahami GIS sebagai analisis data yang memiliki komponen lokasi.
- Menggabungkan data atribut dan koordinat.
- Membandingkan indikator persaingan kerja antarwilayah.

## Menjalankan
```bash
python main.py
```

Koordinat dan angka lowongan hanya ilustrasi, bukan data pasar kerja aktual.
