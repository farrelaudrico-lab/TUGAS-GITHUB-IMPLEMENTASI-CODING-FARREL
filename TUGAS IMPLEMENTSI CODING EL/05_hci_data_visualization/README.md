# 5. Human-Computer Interaction & Data Visualization

## Studi kasus
Pemilik toko membutuhkan dashboard sederhana untuk menjelajahi penjualan berdasarkan kategori produk. Dashboard dirancang agar pengguna bisa memilih kategori dan langsung melihat indikator utama serta grafik.

## Aspek HCI
- **Keterlihatan status:** metrik total dan jumlah transaksi terlihat di bagian atas.
- **Kontrol pengguna:** filter kategori dapat diubah.
- **Konsistensi:** grafik dan tabel menggunakan filter yang sama.
- **Umpan balik:** pilihan filter langsung memperbarui tampilan.

## Menjalankan
```bash
streamlit run app.py
```
Buka alamat lokal yang ditampilkan Streamlit pada terminal.
