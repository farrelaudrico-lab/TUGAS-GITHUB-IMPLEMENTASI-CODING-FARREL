# 1. Make Sense of Data with Analytics and AI

## Studi kasus
Sebuah toko ingin memahami produk dan bulan yang menghasilkan penjualan tertinggi. Data transaksi contoh dianalisis untuk menemukan tren, menghitung pendapatan, dan membuat prediksi sederhana.

## Tujuan
- Mengolah data menggunakan pandas.
- Menghitung total pendapatan per produk dan bulan.
- Membuat model regresi sederhana sebagai contoh penggunaan AI/ML.
- Menghasilkan ringkasan analitik yang mudah dibaca.

## Menjalankan
```bash
python main.py
```

Data contoh dibuat langsung di dalam kode sehingga tidak membutuhkan file dataset eksternal.
