# 6. Attributing Direct Drivers to Deforestation Alerts with Satellite Imagery and AI

## Studi kasus
Sebuah tim pembelajaran ingin memahami bagaimana fitur penginderaan jauh dapat membantu mengelompokkan peringatan perubahan tutupan lahan. Program menggunakan fitur sintetis yang terinspirasi dari indikator pengamatan bumi: perubahan NDVI, perubahan NBR, jarak ke jalan, dan curah hujan.

## Tujuan
- Memahami hubungan fitur penginderaan jauh dan klasifikasi.
- Melatih model Random Forest untuk mengelompokkan penyebab simulasi.
- Melihat laporan klasifikasi dan fitur penting.

## Menjalankan
```bash
python main.py
```

**Batasan penting:** tidak ada citra satelit asli di dalam proyek ini. Label penyebab dibuat secara sintetis untuk demonstrasi. Model tidak membuktikan penyebab deforestasi, tidak menggantikan verifikasi lapangan, dan tidak boleh digunakan untuk menuduh pihak tertentu.
